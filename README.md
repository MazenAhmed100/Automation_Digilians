# Automation_Digilians
Automation Testing Project for Login &amp; Filter Features
This repository contains an automation testing project focused on validating core application functionalities.
The project includes automated test scenarios for the login feature and filter functionality to ensure the application works correctly and efficiently.

Features Tested
Login functionality automation
Filter validation testing
Functional test automation
UI behavior verification

Tools & Technologies
Selenium WebDriver
Java
TestNG
Maven

Objective
The objective of this project is to improve software quality by automating repetitive test cases and verifying that important features work as expected.
